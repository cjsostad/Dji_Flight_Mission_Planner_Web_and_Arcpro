Overview

This is a pair of tools that generate DJI WPML waypoint missions for the Mini 4 Pro. Both produce the same .kmz output but serve different workflows:

  • HTML Browser Tool (DJI_Mission_Planner.html): Standalone, no install — draw a polygon on an interactive map, set parameters, and download a KMZ. Best for quick missions in the field.
  • ArcGIS Pro Toolbox (DJI_Waypoint_Mission.pyt): Integrates with your GIS workflow — uses existing polygon feature classes, projects to BC Albers automatically, supports DEM-based terrain following, and writes preview layers to your active map.

Both tools generate a lawnmower (boustrophedon) waypoint pattern within your survey polygon, with optional double cross-hatch grids, terrain following, and per-waypoint photo capture.

What's New in v5 v5.0

  • Mission Name — embedded in KMZ metadata; in the HTML version it also becomes the filename prefix
  • Front & Side Overlap % dropdowns — auto-calculate Photo Interval and Strip Spacing based on altitude and Mini 4 Pro camera FOV
  • Auto-detect Optimal Strip Direction — finds the polygon's long axis and aligns strips to it, minimizing turn time
  • Edge Buffer — insets the polygon inward by N units before generating the grid (safety margin from treelines, fences, restricted boundaries)
  • Hover Time at Waypoints — adds a stabilization pause before each photo to reduce motion blur, especially in wind
  • AE Lock at First Waypoint — adds a 3-second hover at waypoint 0 to let the camera settle on a consistent exposure
  • Imperial Units toggle — switches all distance inputs and stats between metric (m, ha) and imperial (ft, acres). Speed remains m/s (DJI WPML native)
  • Survey Area display — shown live in hectares or acres
  • HTML imagery basemap toggle — switch between OpenStreetMap and ESRI World Imagery
  • HTML camera footprint overlay — visualize each waypoint's actual ground coverage as a transparent rectangle

HTML Browser Tool

Open DJI_Mission_Planner.html in any modern browser (Chrome, Firefox, Edge, Safari). No install required. The tool runs entirely in the browser; only the optional terrain-following feature requires internet access.

Workflow

  1. Choose your basemap (Street or Imagery) and units (Metric or Imperial)
  2. Click Draw Polygon and trace your survey area
  3. Optionally enter a Mission Name and an Edge Buffer
  4. Set altitude, speed, and overlap percentages (or strip spacing/photo interval directly)
  5. Toggle Auto-detect Strip Direction if you want the optimal long-axis alignment
  6. Set Camera, Mission Behavior, and Options as needed
  7. Click Generate Mission — waypoints render on the map with statistics
  8. Click Download KMZ to save the mission file
Tip: Toggle Show Camera Footprint Overlay after generating to see actual ground coverage at each waypoint. This is the fastest way to verify your overlap settings produce the coverage you expect.

Imagery Basemap

The Imagery option uses ESRI World Imagery tiles — the same satellite layer used in ArcGIS Online. It includes a labels overlay so road and place names remain visible. No API key required. For dense forests or rural areas, imagery is much more useful than OSM streets when locating survey boundaries.

Imperial Units

When toggled, all distance inputs (altitude, strip spacing, photo interval, edge buffer) display and accept feet. Survey area displays in acres. Internally everything is converted to metres for the calculations and the WPML output. Speed stays in m/s in both modes because DJI Pilot 2 expects m/s natively.

Switching units mid-session converts existing values automatically — entering 60 in metric mode then toggling Imperial will display 196.85.

ArcGIS Pro Toolbox

Add DJI_Waypoint_Mission.pyt to your project: Catalog Pane → right-click Toolboxes → Add Toolbox.

The tool processes selected polygon features. If multiple features are selected, each is processed and the waypoints are concatenated. The tool reprojects to BC Albers (EPSG:3005) internally for accurate metric calculations regardless of your input projection.

Output

  • KMZ file at the path you specify — ready for DJI Pilot 2
  • DJI_Waypoints point feature class in your scratch GDB with full attribute table (waypoint index, strip number, altitude, terrain elevation, terrain adjustment, hover seconds, gimbal, distance from previous, cumulative distance, lat, lon)
  • DJI_FlightPath polyline feature class with mission-level summary attributes (mission name, total waypoints, distance, time, area in hectares and acres, AE lock, terrain source, generation timestamp)

Both feature classes are added to your active map automatically when Add Preview Layers is checked, with waypoints symbolized by altitude using a graduated color ramp.

Overlap & Coverage

The Front and Side Overlap % dropdowns calculate Photo Interval and Strip Spacing from the camera's ground footprint at your altitude:

Footprint width  (cross-track) = 2 × altitude × tan(HFOV/2)
Footprint height (along-track) = 2 × altitude × tan(VFOV/2)

Strip Spacing  = Footprint width  × (1 - SideOverlap%)
Photo Interval = Footprint height × (1 - FrontOverlap%)

For the Mini 4 Pro: HFOV = 82.1°, VFOV = 65.2°. So at 60 m AGL, the footprint is approximately 104 m wide × 77 m deep on flat ground.

Note on AE Lock: The Mini 4 Pro consumer drone does not expose a true AE Lock element in WPML. The "AE Lock at First Waypoint" option adds a 3-second hover at waypoint 0 to let the camera settle on consistent exposure before the first photo. For maximum exposure consistency, also enable AE Lock manually in DJI Fly before launching the mission.

Terrain Following

When enabled, each waypoint's altitude is adjusted based on the terrain elevation at that point relative to the takeoff location:

executeHeight[i] = desiredAGL + (terrainElev[i] - homeElev)

So if you specify 60 m AGL and the terrain rises 30 m over the survey area, the drone climbs to 90 m above takeoff at that point — maintaining a constant 60 m above the ground. A 10 m safety floor is enforced.

Elevation sources

  • Open-Meteo API (default in both tools): Free, no API key, ~90 m resolution (Copernicus GLO-90 DEM). Requires internet.
  • Local DEM raster (ArcGIS Pro only): Higher resolution if you have it. The tool falls back to Open-Meteo if local sampling fails.
Terrain following is not obstacle avoidance. The DEM represents the bare earth, not trees or buildings. If you're surveying a forest at 60 m AGL with terrain following enabled, the drone is 60 m above the bare ground — but only ~30 m above 30 m tall trees. Always set your altitude with this in mind.

Loading the Mission onto the RC

RC Pro + DJI Pilot 2

  1. Connect the RC Pro to your computer via USB
  2. Navigate to Android/data/dji.go.v5/files/waypoint/
  3. Open one of the random-name folders and replace its existing KMZ with yours, keeping the original filename
  4. In DJI Pilot 2, open Waypoint Mission and your replaced mission appears with its original name but your contents

RC2 + DJI Fly

DJI Fly does not natively import WPML missions. The same file-replacement workaround applies, but in Android/data/dji.go.v5/files/waypoint/ on the RC2's storage. Some RC2 firmware versions block this — your mileage may vary.

iOS DJI Fly

Use the Files app to copy the KMZ to DJI Fly/wayline_mission/. The mission becomes available in the waypoint mission list.

Tips & Best Practices

  • Set Auto-detect Strip Direction for any non-square polygon. Strips along the long axis means fewer turns and significantly less battery time wasted on turning around.
  • Use overlap percentages instead of manual strip spacing/photo interval for predictable photogrammetry results. The calculations match what Pix4D and Agisoft Metashape expect.
  • Keep hover time under 2 seconds unless wind is significant. Each second of hover at every waypoint adds up — at 500 waypoints, 2 s of hover = 16 minutes added to the mission.
  • Use edge buffer for tree-edge surveys — even a 5 m setback gives a meaningful safety margin. The Mini 4 Pro's GPS hold can drift 1–2 m on its own.
  • Verify with the camera footprint preview in the HTML version. If you see gaps between footprints, your overlap is too low. If you see massive overlap, you're wasting battery.
  • Test the mission flow on the RC before flying — DJI Pilot 2's mission preview shows the drone path and lets you verify altitude transitions are reasonable.

Legal & Safety

Canada (Transport Canada): The default 120 m AGL limit applies to Basic Operations. Above 120 m AGL or within 5.6 km of an aerodrome requires Advanced Operations certification or an SFOC. The tool warns when altitude exceeds 120 m but does not check airspace — always verify on the NAV CANADA Drone Site Selection Tool before flying.

The drone operator is responsible for verifying:

  • Airspace classification and proximity to controlled airspace
  • NOTAMs and TFRs in effect
  • Visual line-of-sight throughout the mission
  • Weather conditions including wind, precipitation, and icing
  • Privacy and trespass considerations for the survey area

This tool generates a flight plan; it does not replace pre-flight checks, situational awareness, or the operator's judgment.
